# Brand and company research track

**Status:** Parallel discovery; no name selected

Brand work is deliberately separate from product contracts and platform architecture. Implementation uses the neutral placeholders documented in ADR 0003 until a brand decision is accepted.

## Workstreams

1. Positioning and category language.
2. Company and product naming.
3. Trademark, company-registry, domain, package, social, and open-source collision checks.
4. Voice, visual identity, and naming system for platform components.
5. Open-source project versus commercial product relationship.

## Rules

- Candidate names do not enter source code, API groups, event taxonomies, domains, or package registries during research.
- Every candidate records pronunciation, meaning, negative associations, international concerns, and collision checks.
- Legal/trademark availability requires professional verification; search results are screening only.
- Decide whether company, platform, open-source project, and assistant need one name or a hierarchy before scoring candidates.

Use the [naming brief](naming-brief.md) as the first working document.
