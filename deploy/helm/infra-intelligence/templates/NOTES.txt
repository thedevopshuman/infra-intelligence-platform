The foundation API service is available inside the cluster at:

  http://{{ include "infra-intelligence.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}

The API fails closed unless its configured authentication mode has valid protected configuration.
Chart values are closed by values.schema.json; validate the exact protected values file
with both helm lint and helm template before applying it.
Optional ingress requires an existing TLS Secret, explicit controller class, redirect
annotation, NetworkPolicy, and exact controller namespace/pod selectors.
For a fresh PostgreSQL-backed install, provide database.existingSecret and explicitly
set database.migrations.enabled=true. The pre-install/pre-upgrade migration hook
must succeed before serving workloads roll out; API readiness never applies migrations.
For durable background investigations and non-replaying action timers, set
worker.enabled=true, database.existingSecret, and at least one exact
worker.tenants entry. The workflow worker has no wildcard tenant mode.
Production rollout still requires customer-specific identity, policy, credential-broker,
network-policy, telemetry, storage recovery, and SLO validation.
